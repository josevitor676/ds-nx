## Slot de ações

O Header expõe a prop `actions` como um slot livre onde o desenvolvedor compõe os botões que desejar. Use `IconButton` e `HeaderProfile` para manter consistência visual.

```tsx
import { Header, HeaderProfile, IconButton } from "@nexusshield/design-system"
import { Icon } from "@nexusshield/design-system"
import { IconBell, IconSettings } from "@tabler/icons-react"
;<Header
  appName="Minha App"
  actions={
    <>
      <IconButton
        icon={<Icon icon={IconBell} size="md" />}
        aria-label="Notificações"
        variant="clear"
        colorVariant="primary"
        className="ds-rounded-sm ds-text-white hover:ds-bg-primary-700"
        onClick={handleBell}
      />
      <IconButton
        icon={<Icon icon={IconSettings} size="md" />}
        aria-label="Configurações"
        variant="clear"
        colorVariant="primary"
        className="ds-rounded-sm ds-text-white hover:ds-bg-primary-700"
        onClick={handleSettings}
      />
      <HeaderProfile userName="Tiago Sanches" userRole="Desenvolvedor" onLogout={handleLogout} />
    </>
  }
/>
```

## Acessibilidade

- ⌨️ O botão de sidebar possui `aria-label="Alternar menu lateral"`.
- 🔊 O campo de busca tem `aria-label` igual ao `searchPlaceholder`, garantindo anúncio correto em AT.
- 🖼️ Quando `logoSrc` é fornecido, o elemento `<img>` recebe `alt` com o nome da aplicação. O logo padrão SVG é marcado com `aria-hidden="true"`.
- 👤 O `HeaderProfile` usa `aria-label="Perfil do usuário"` e o dropdown é gerenciado pelo `@radix-ui/react-popover` (inclui `aria-expanded`, `aria-haspopup` e fechamento via `Escape`).
- ♿ Botões passados via `actions` devem ter `aria-label` descritivo — responsabilidade do consumidor.
- 📱 Em viewports menores que `sm` (640 px), o nome da aplicação é ocultado para economizar espaço.
