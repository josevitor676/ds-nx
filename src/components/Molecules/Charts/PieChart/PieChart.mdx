## Acessibilidade

- O container do gráfico é um `<div>` neutro — adicione `aria-label` para descrever o conteúdo (ex: `aria-label="Distribuição de categorias"`).
- O tooltip gerado pelo SVG nativo é acessível via teclado na maioria dos navegadores modernos.
- Para leitores de tela, forneça sempre uma alternativa textual ou tabela com os mesmos dados.
- Ao usar `CustomColors`, certifique-se de que cada cor possui contraste mínimo de 3:1 com o fundo.
