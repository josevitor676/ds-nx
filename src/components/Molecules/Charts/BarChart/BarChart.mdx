## Acessibilidade

- O container do gráfico é um `<div>` neutro — adicione `aria-label` para descrever o conteúdo quando necessário (ex: `aria-label="Vendas mensais de 2024"`).
- O tooltip gerado pelo SVG nativo é acessível via teclado na maioria dos navegadores modernos.
- Para leitores de tela, considere complementar o gráfico com uma tabela de dados alternativa.
- As cores dos tokens do DS têm relação de contraste mínima de 3:1 com o fundo branco.
