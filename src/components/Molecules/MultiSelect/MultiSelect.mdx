## Quando usar

- **Filtros** — quando o usuário precisa selecionar múltiplos critérios de filtragem ao mesmo tempo (ex: categorias, regiões, status).
- **Formulários de configuração** — quando um campo aceita mais de um valor (ex: permissões, tags, usuários responsáveis).
- **Seleção em listas curtas** — quando o número de opções é entre 3 e ~20 itens.

## Quando não usar

- **Seleção única** — use o **Select** quando apenas um valor pode ser escolhido.
- **Listas muito longas** — para centenas de opções, prefira um componente com busca/autocomplete.
- **Confirmação de ação** — para confirmar ou negar uma única opção, use **Checkbox** ou **Switch**.

## Acessibilidade

- ⌨️ O trigger é navegável por teclado via Tab; `Enter` e `Espaço` abrem/fecham o menu.
- 🔊 `aria-expanded`, `aria-haspopup`, `aria-controls` e `aria-labelledby` são aplicados automaticamente no trigger.
- 📍 `aria-current` não se aplica — use `aria-invalid={true}` via prop `error` para indicar erros ao AT.
- 🚫 No estado `disabled`, `tabIndex={-1}` e `aria-disabled={true}` são aplicados.
- ⭐ `mandatory={true}` aplica `aria-required={true}` no trigger e exibe asterisco com `aria-hidden={true}`.
- 🎨 As combinações de cor atendem ao contraste mínimo WCAG AA.
