## Variantes

### Com conteúdo (`children`)
Utilize a prop `children` para inserir qualquer conteúdo na área central do modal — formulários, listas ou texto descritivo.

<Canvas of={ModalStories.WithContent} />

### Sem subtítulo
Use quando o título já é suficientemente descritivo e não é necessário texto de suporte.

<Canvas of={ModalStories.WithoutSubtitle} />

### Sem rodapé
Use quando o modal é apenas informativo e não requer ações do usuário (ex: detalhe de visualização).

<Canvas of={ModalStories.WithoutFooter} />

### Sem botão fechar
Use quando o modal deve ser encerrado obrigatoriamente pelos botões do rodapé (impede fechar via ESC ou clique no overlay também é recomendado para fluxos críticos).

<Canvas of={ModalStories.WithoutCloseButton} />

## Acessibilidade

- **Papel semântico**: O modal usa `role="dialog"` e `aria-modal="true"` automaticamente via Radix UI Dialog.
- **Título acessível**: A prop `title` é vinculada via `aria-labelledby` ao `Dialog.Title`, tornando o conteúdo anunciável por leitores de tela.
- **Descrição acessível**: A prop `subtitle` é vinculada via `aria-describedby` ao `Dialog.Description`.
- **Teclado**: Pressionar `Escape` fecha o modal. O foco é aprisionado dentro do painel enquanto aberto (focus trap via Radix).
- **Botão fechar**: O `IconButton` do cabeçalho possui `aria-label="Fechar modal"` para leitores de tela.
- **Retorno do foco**: Ao fechar, o foco retorna automaticamente ao elemento que abriu o modal.
- **Contraste**: Texto do título usa `neutral-800` (#363843) e o subtítulo usa `neutral-600` (#646981), ambos com contraste suficiente sobre fundo branco.
