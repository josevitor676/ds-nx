## Variantes

### Tabela simples

Tabela básica com colunas de texto e ícone de ordenação.

<Canvas of={DataTableStories.Default} />

### Zebra striping (`striped`)

Prop `striped` alterna o fundo das linhas ímpares para `neutral-25`, facilitando a leitura em tabelas largas.

<Canvas of={DataTableStories.Striped} />

### Ordenação (`sortable`)

Colunas com `sortable: true` exibem o botão de ordenação no cabeçalho. Ao clicar, o ciclo é: crescente → decrescente → sem ordenação. No modo não-controlado, os dados são reordenados internamente. No modo controlado, passe `sortColumn`, `sortDirection` e `onSort`.

<Canvas of={DataTableStories.Sortable} />

### Filtragem (`filterable`)

Colunas com `filterable: true` exibem o ícone de filtro no cabeçalho. O estado ativo (`filterActive`) é controlado externamente.

<Canvas of={DataTableStories.Filterable} />

### Seleção de linhas (`selectable`)

Prop `selectable` adiciona uma coluna de checkboxes para seleção individual e em massa. O estado é controlado externamente via `selectedRows` e `onRowSelect`.

<Canvas of={DataTableStories.Selectable} />

## Acessibilidade

- A tabela usa HTML semântico (`<table>`, `<thead>`, `<tbody>`, `<th scope="col">`, `<td>`) para garantir leitura correta por leitores de tela.
- Passe `aria-label` no `DataTable` para identificar a tabela para tecnologias assistivas (ex: `aria-label="Tabela de colaboradores"`).
- Os botões de ordenação possuem `aria-label` dinâmico indicando o estado atual: "Ordenação crescente", "Ordenação decrescente" ou "Ordenar coluna".
- O botão de filtro possui `aria-label="Filtrar coluna"`.
- O checkbox de seleção total no cabeçalho possui `aria-label="Selecionar todas as linhas"`.
- O estado `indeterminate` no checkbox de "selecionar tudo" é ativado automaticamente quando apenas algumas linhas estão selecionadas.
- Todos os controles interativos são focáveis via teclado e possuem anel de foco visível (`focus-visible:ring`).
- Navegação por teclado em checkboxes: `Space` alterna o estado; formulários de tabela aceitam `Tab` para percorrer células.
