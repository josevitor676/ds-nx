## Estados

- **`loading`** — desabilita o botão e exibe spinner. Use durante chamadas assíncronas.
- **`disabled`** — atributo HTML nativo. Bloqueia interação em todas as variantes.

## Acessibilidade

- ⌨️ Totalmente navegável por teclado (Tab para foco, Enter/Space para ativar).
- 🔊 Usa elemento `<button>` nativo — leitores de tela anunciam corretamente o papel e o estado.
- 🔒 O atributo `disabled` bloqueia interação e é comunicado ao AT (Assistive Technology) nativamente.
- ⏳ Durante `loading`, o botão é desabilitado automaticamente para evitar duplo envio.
- 🎨 Todas as combinações de variant + color atendem ao contraste mínimo WCAG AA (4.5:1).
