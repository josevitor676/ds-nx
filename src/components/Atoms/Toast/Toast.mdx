## Uso

O Toast é disparado via hook `useToast`, que deve estar dentro de um `ToastProvider`.

```tsx
// 1. Envolva sua aplicação com o provider
import { ToastProvider } from '@gazin/design-system';

function App() {
  return (
    <ToastProvider defaultPosition="top-right" defaultDuration={3000}>
      <MinhaApp />
    </ToastProvider>
  );
}
```

```tsx
// 2. Use o hook para disparar toasts
import { useToast } from '@gazin/design-system';

function MinhaApp() {
  const { toast } = useToast();

  return (
    <button onClick={() => toast({
      title: 'Salvo!',
      subTitle: 'Os dados foram salvos com sucesso.',
      type: 'success',
    })}>
      Salvar
    </button>
  );
}
```

## Tempo de exibição

- **Padrão**: 3000ms (3 segundos)
- Configurável via `defaultDuration` no `ToastProvider` ou `duration` por toast individual
- Use `duration: 0` para manter o toast até o usuário fechar manualmente

```tsx
toast({ title: 'Ação necessária', type: 'warning', duration: 0 });
toast({ title: 'Info', type: 'information', duration: 5000 });
```

---

## Posicionamento

Defina a posição padrão no `ToastProvider` ou por toast individual via `position`.

| Valor | Descrição |
|-------|-----------|
| `top-right` | Canto superior direito (padrão) |
| `top-left` | Canto superior esquerdo |
| `top-center` | Centro superior |
| `bottom-right` | Canto inferior direito |
| `bottom-left` | Canto inferior esquerdo |
| `bottom-center` | Centro inferior |

## Acessibilidade

- Usa `role="alert"` e `aria-live="polite"` — leitores de tela anunciam automaticamente
- Botão de fechar possui `aria-label="Fechar notificação"`
- Ícones marcados com `aria-hidden="true"`
- Renderizado via Portal no `document.body` com `z-index: 9999`
