## Quando usar

- **Links em texto** — dentro de parágrafos ou frases onde é necessário referenciar outra página sem quebrar a leitura.
- **Ações de rodapé** — em tabelas ou modais, para ações como "Saiba mais" que devem ter menos peso que os botões.
- **Navegação de suporte** — como o "Esqueci minha senha" em telas de login, onde o foco principal deve ser o botão de entrar.

## Quando não usar

- **Ação principal da página** — nunca use para a ação mais importante (ex: "Comprar agora", "Salvar"); use um **Button**.
- **Navegação de breadcrumb** — para trilhas de navegação, utilize o componente **BreadcrumbItem**.

## Acessibilidade

- ⌨️ Navegável por teclado — o elemento `<a>` recebe foco naturalmente via Tab.
- 🔊 Usa elemento `<a>` nativo — leitores de tela anunciam o texto do link corretamente.
- 🚫 No estado `disabled`, o `href` é removido, `tabIndex` passa a `-1` e `aria-disabled="true"` é aplicado.
- 🖼️ Os ícones (`leftIcon` e `rightIcon`) são envolvidos com `aria-hidden={true}` para não gerar ruído em leitores de tela.
- 🎨 As combinações de cor atendem ao contraste mínimo WCAG AA: `primary-500` e `neutral-600` sobre fundo branco.
