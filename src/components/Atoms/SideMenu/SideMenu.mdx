## Composição

O SideMenu é composto por **quatro sub-componentes** que trabalham juntos:

| Componente | Elemento | Papel |
|---|---|---|
| `SideMenu` | `<nav>` | Container principal. Define a largura e o estado `collapsed`. |
| `SideMenuGroup` | `<div>` + `<ul>` | Agrupador de itens. Aceita `label` opcional exibido como rótulo de seção. |
| `SideMenuItem` | `<li>` + `<button>` | Item de navegação. Suporta ícone, badge, `active`, `disabled` e sub-itens expansíveis. |
| `SideMenuSubItem` | `<li>` + `<button>` | Sub-item de navegação, aninhado dentro de `SideMenuItem` via `children`. |

```tsx
<SideMenu>
  <SideMenuGroup label="NAVEGAÇÃO">
    <SideMenuItem icon={<HomeIcon />} label="Dashboard" active />
    <SideMenuItem icon={<ChartIcon />} label="Relatórios">
      <SideMenuSubItem label="Mensal" active />
      <SideMenuSubItem label="Anual" />
    </SideMenuItem>
  </SideMenuGroup>
</SideMenu>
```

## Estados do item

`SideMenuItem` tem três estados visuais: **default**, **active** e **disabled**.
Use `active` para indicar a página atual e `disabled` para bloquear a interação.

## Sub-itens

Use `defaultExpanded` para iniciar o item já aberto.

## Badge

A prop `badge` exibe um contador numérico ao lado do label do item.
Aceita `string | number`. Útil para indicar notificações ou contagens pendentes.

## Modo colapsado

Quando `collapsed={true}`, o menu exibe apenas ícones (sem labels e sem sub-itens).
O atributo `title` é adicionado automaticamente ao item para exibir o label via tooltip nativo do navegador.

## Acessibilidade

- ⌨️ Totalmente navegável por teclado (Tab para foco, Enter/Space para ativar ou expandir).
- 🔊 Container usa `<nav aria-label="Side navigation">` para leitores de tela.
- 🏷️ Itens usam `aria-current="page"` no item com `active` para sinalizar a página atual ao AT.
- ▶️ Itens com sub-menus expõem `aria-expanded` para indicar estado aberto/fechado.
- 🔒 Itens desabilitados recebem o atributo `disabled` nativo — comunicado ao AT automaticamente.
- 📌 No modo `collapsed`, `title={label}` é adicionado ao botão para expor o nome via tooltip nativo.
