## Seleção de range

O componente opera em dois cliques:

1. **Primeiro clique** — define `startDate`; `endDate` fica `null`. O componente entra no modo de seleção de fim.
2. **Segundo clique** — define `endDate`. Se a data clicada for anterior ao `startDate`, as datas são trocadas automaticamente.
3. **Hover entre os cliques** — preview visual do range é exibido em tempo real.

## Estados visuais dos dias

| Estado | Aparência | Quando ocorre |
|---|---|---|
| `default` | Texto `neutral-500`, hover `primary-25` | Dias normais do mês |
| `dim` | Texto `neutral-300` | Dias de meses adjacentes |
| `in-range` | Fundo `primary-25`, texto `neutral-500` | Dias entre início e fim |
| `start` | Fundo `primary-500`, texto branco, arredondado à esquerda | Data de início |
| `end` | Fundo `primary-500`, texto branco, arredondado à direita | Data de fim |
| `start-end` | Fundo `primary-500`, texto branco, totalmente arredondado | Quando início = fim |

## Navegação

O header expõe quatro controles de navegação:

- **`◀◀` / `▶▶`** — avança ou recua 12 meses (ano)
- **`◀` / `▶`** — avança ou recua 1 mês

Cada lado também possui um botão dropdown que abre uma lista vertical com os 12 meses.
Ao abrir o picker de um lado, o botão do lado oposto é desabilitado para evitar conflito.

## Acessibilidade

- ⌨️ Todos os botões de navegação e seleção são elementos `<button>` nativos com `aria-label` descritivo.
- ⌨️ Os botões de mês possuem `aria-expanded` que reflete o estado aberto/fechado do picker.
- ⌨️ A grade de dias é navegável por Tab; o foco é visível via `focus-visible:ring`.
- 🎨 As combinações de cor do estado `selected` (`primary-500` sobre branco) e `in-range` atendem ao contraste WCAG AA.
