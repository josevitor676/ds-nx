## Estados

- **`default`** — fundo transparente, texto `neutral-600`.
- **`hover`** — fundo `neutral-50` ao passar o cursor.
- **`selected`** — fundo `primary-25`, texto e ícone `primary-500`.
- **`disabled`** — opacidade reduzida, cursor `not-allowed`, sem hover.

## Uso com Button e Popover

<Canvas of={DropdownStories.WithButtonTrigger} />

```tsx
import * as RadixPopover from "@radix-ui/react-popover"
import { Button, Dropdown, DropdownItem } from "@your-org/design-system"
import { IconEdit, IconShare2, IconTrash } from "@tabler/icons-react"

export function Example() {
  return (
    <RadixPopover.Root>
      <RadixPopover.Trigger asChild>
        <Button size="sm" variant="outlined">Abrir menu</Button>
      </RadixPopover.Trigger>

      <RadixPopover.Portal>
        <RadixPopover.Content side="bottom" align="start" sideOffset={8}>
          <Dropdown>
            <DropdownItem icon={IconShare2} label="Compartilhar" />
            <DropdownItem icon={IconEdit} label="Editar" />
            <DropdownItem icon={IconTrash} label="Excluir" />
          </Dropdown>
        </RadixPopover.Content>
      </RadixPopover.Portal>
    </RadixPopover.Root>
  )
}
```

## Acessibilidade

- O container `Dropdown` possui `role="menu"` para leitores de tela.
- Cada `DropdownItem` possui `role="menuitem"` para identificação correta.
- O estado desabilitado usa o atributo `disabled` nativo do HTML, garantindo bloqueio por teclado e mouse.
- O estado selecionado é declarado visualmente via classes de cor; para uso em menus acessíveis, considere adicionar `aria-selected` ou `aria-current` conforme o contexto de navegação.
- Certifique-se de encapsular o `Dropdown` em um componente com `aria-expanded` quando usado como menu flutuante.
