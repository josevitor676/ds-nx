## Instalação

O componente `Icon` já vem com o DS, mas os ícones em si são uma **peer dependency**. Isso garante tree-shaking — só os ícones que você importar entram no bundle.

```bash
# npm
npm install @tabler/icons-react

# yarn
yarn add @tabler/icons-react

# pnpm
pnpm add @tabler/icons-react
```

> O DS é compatível com `@tabler/icons-react` na versão **^3.0.0**.

## Quick start

```tsx
import { Icon } from '@gazin/design-system';
import { IconMail } from '@tabler/icons-react';

function Example() {
  return <Icon icon={IconMail} size="md" />;
}
```

O fluxo é sempre o mesmo:

1. Importe o componente `Icon` do DS
2. Importe o ícone desejado de `@tabler/icons-react`
3. Passe o ícone via prop `icon`

## Tamanhos

O componente expõe três tamanhos semânticos via prop `size`. Use-os de forma consistente com os demais componentes do DS.

| Token | Pixels | Uso recomendado |
|-------|--------|-----------------|
| `sm`  | 16px   | Dentro de botões, inputs, badges |
| `md`  | 20px   | Uso geral, navegação, listas |
| `lg`  | 24px   | Headers, empty states, destaque |

## Espessura do traço

A prop `stroke` controla a espessura do traço do ícone. O padrão do Tabler é `2`, mas o DS adota `1.5` como padrão nos componentes (ex: `Button`) para um visual mais leve e alinhado ao sistema. Use `stroke` diretamente no `Icon` quando precisar de um valor diferente.

<Canvas of={IconStories.Strokes} />

```tsx
<Icon icon={IconHome} size="lg" stroke={1.5} />
```

## Composição com outros componentes

### Button

O `Button` aceita ícones Tabler diretamente via `iconStart` e `iconEnd` — passe a **referência do componente**, não o elemento instanciado.

```tsx
import { Button } from '@gazin/design-system';
import { IconMail, IconArrowRight, IconPlus } from '@tabler/icons-react';

// ✅ correto — referência do componente
<Button iconStart={IconMail}>E-mail</Button>
<Button iconEnd={IconArrowRight}>Próximo</Button>

// ❌ errado — não passe o elemento instanciado
<Button iconStart={<IconMail />}>E-mail</Button>
```

O tamanho do ícone é derivado automaticamente do `size` do botão (`sm`/`md` → 16px, `lg` → 20px). Quando necessário, use as props de override:

| Prop | Padrão | Descrição |
|------|--------|-----------|
| `iconStroke` | `1.5` | Espessura do traço dos ícones |
| `iconSize` | derivado de `size` | Sobrescreve o tamanho automático |

```tsx
// stroke personalizado
<Button iconStart={IconMail} iconStroke={2}>E-mail</Button>

// tamanho fixo independente do size do botão
<Button size="sm" iconStart={IconMail} iconSize="lg">E-mail</Button>
```

## Tipagem

O DS re-exporta o tipo `TablerIcon` para que você possa tipar props que recebem ícones sem importar diretamente do pacote Tabler.

```tsx
import { Icon, type TablerIcon } from '@gazin/design-system';

// Use em interfaces de componentes que aceitam ícones
interface NavItemProps {
  icon: TablerIcon;
  label: string;
  href: string;
}

function NavItem({ icon, label, href }: NavItemProps) {
  return (
    <a href={href}>
      <Icon icon={icon} size="sm" />
      {label}
    </a>
  );
}
```

## Cor

Os ícones Tabler herdam `currentColor` por padrão. Para mudar a cor, basta aplicar `color` via CSS no elemento pai ou diretamente no componente.

```tsx
{/* Herda a cor do pai */}
<span style={{ color: 'var(--ds-color-error-500)' }}>
  <Icon icon={IconAlertCircle} size="md" />
</span>

{/* Ou via prop color diretamente */}
<Icon icon={IconCheck} size="md" color="var(--ds-color-success-500)" />
```

## Acessibilidade

- O componente aplica `aria-hidden="true"` por padrão — ícones decorativos não devem ser anunciados por leitores de tela.
- Quando o ícone for o **único conteúdo** de um botão (ex: `IconButton`), garanta que o elemento pai tenha `aria-label` descritivo.
- Nunca use ícones como única forma de comunicar informação — sempre acompanhe com texto ou tooltip.

## FAQ

**Por que `@tabler/icons-react` é peer dependency e não vem embutido no DS?**

Para garantir tree-shaking. O pacote tem +5.000 ícones — se fosse bundlado no DS, todos iriam para o seu bundle final. Como peer dependency, o bundler do seu projeto (Vite, webpack, etc.) inclui apenas os ícones que você efetivamente importa.

**Posso usar ícones Tabler sem o componente `Icon`?**

Sim. Os componentes Tabler funcionam standalone. O wrapper `Icon` existe para padronizar tamanhos semânticos (`sm`, `md`, `lg`) e garantir `aria-hidden` automático — mas não é obrigatório.

**Como encontro o nome de um ícone específico?**

Acesse [tabler.io/icons](https://tabler.io/icons), busque pelo nome e converta para PascalCase com prefixo `Icon` (ex: `arrow-right` → `IconArrowRight`).
