# Instalar Biblioteca

A biblioteca está publicada no **npmjs.com** — nenhuma configuração de registry adicional é necessária.

Instale a biblioteca e as peer dependencies no projeto consumidor:

### npm

```bash
npm install @nexusshield/design-system react react-dom @tabler/icons-react
```

### pnpm

```bash
pnpm add @nexusshield/design-system react react-dom @tabler/icons-react
```

### yarn

```bash
yarn add @nexusshield/design-system react react-dom @tabler/icons-react
```

Depois da instalação, importe o CSS global da biblioteca no entrypoint da aplicação:

```tsx
import "@nexusshield/design-system/index.css"
```

# Configurar ThemeProvider

Envolva o entrypoint da aplicação com o `ThemeProvider`:

```tsx
import { StrictMode } from "react"
import { createRoot } from "react-dom/client"
import { ThemeProvider } from "@nexusshield/design-system"
import "@nexusshield/design-system/index.css"
import App from "./App"

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <ThemeProvider initialTheme="default">
      <App />
    </ThemeProvider>
  </StrictMode>
)
```

# Usar componentes

```tsx
import { Button, Input } from "@nexusshield/design-system"

export function Example() {
  return (
    <div style={{ display: "grid", gap: 12, maxWidth: 320 }}>
      <Input label="Nome" placeholder="Digite seu nome" />
      <Button>Salvar</Button>
    </div>
  )
}
```
