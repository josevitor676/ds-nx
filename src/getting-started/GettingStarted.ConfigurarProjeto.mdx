# Configurar Projeto

A biblioteca está publicada no **npmjs.com** — nenhuma configuração de registry adicional é necessária.

## 1. Instalar dependências

```bash
npm install @nexusshield/design-system react react-dom @tabler/icons-react
```

## 2. Configurar o ThemeProvider

Envolva o entrypoint da aplicação com o `ThemeProvider`:

```tsx
import { StrictMode } from "react"
import { createRoot } from "react-dom/client"
import { ThemeProvider } from "@nexusshield/design-system"
import "@nexusshield/design-system/index.css"
import App from "./App"

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <ThemeProvider initialTheme="default">
      <App />
    </ThemeProvider>
  </StrictMode>
)
```

> O import `@nexusshield/design-system/index.css` já carrega o CSS compilado da biblioteca (tokens, variáveis e estilos base dos componentes). Não é necessário configurar Tailwind no projeto consumidor.

## 3. Usar componentes

```tsx
import { Button, Input } from "@nexusshield/design-system"

export function Example() {
  return (
    <div style={{ display: "grid", gap: 12, maxWidth: 320 }}>
      <Input label="Nome" placeholder="Digite seu nome" />
      <Button>Salvar</Button>
    </div>
  )
}
```

## Trocar tema dinamicamente

Para alternar temas em runtime, use o hook `useTheme`:

```tsx
import { useTheme } from "@nexusshield/design-system"

export function ThemeSwitcher() {
  const { theme, setTheme, availableThemes } = useTheme()

  return (
    <select value={theme} onChange={(e) => setTheme(e.target.value as typeof theme)}>
      {availableThemes.map((item) => (
        <option key={item.name} value={item.name}>
          {item.label}
        </option>
      ))}
    </select>
  )
}
```
