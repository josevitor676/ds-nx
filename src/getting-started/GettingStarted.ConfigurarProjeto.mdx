# Configurar Projeto

Envolva a aplicacao com o ThemeProvider para aplicar os tokens CSS do Design System.

```tsx
import React from "react"
import ReactDOM from "react-dom/client"
import { ThemeProvider } from "@nexusshield/design-system"
import "@nexusshield/design-system/index.css"
import { App } from "./App"

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <ThemeProvider initialTheme="default">
      <App />
    </ThemeProvider>
  </React.StrictMode>
)
```

Se quiser trocar tema dinamicamente dentro da app, use o hook useTheme.

```tsx
import { useTheme } from "@nexusshield/design-system"

export function ThemeSwitcher() {
  const { theme, setTheme, availableThemes } = useTheme()

  return (
    <select value={theme} onChange={(e) => setTheme(e.target.value as typeof theme)}>
      {availableThemes.map((item) => (
        <option key={item.name} value={item.name}>
          {item.label}
        </option>
      ))}
    </select>
  )
}
```
